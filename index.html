Taller de HTML5 y CSS

A. CSS en línea (Inline)

Este encabezado usa el atributo style directamente en la etiqueta para cambiar color, tamaño y alineación. El CSS en línea tiene mayor prioridad que el interno y el externo.

B. CSS interno (Internal)

Las fuentes de los encabezados h1, h2 y h3 se definen en la etiqueta <style> dentro del <head>.

C. CSS externo (External)

Los colores, fondos y bordes vienen del archivo style.css, enlazado con la etiqueta <link>.
